## 常用操作速查

命令行版（三条命令走完一个循环）：

```bash
git status              # 先看现在什么情况
git add .               # 把改动放进托盘
git commit -m "说明"    # 存档
git push                # 上传到 GitHub
```

VS Code 图形界面版（鼠标点，等价于上面）：

| 界面上的东西 | 相当于 |
| --- | --- |
| 文件右边的 `+` 号 | `git add` |
| 消息框 + `✓` 提交按钮 | `git commit` |
| 「同步更改」按钮 | `git push` |
